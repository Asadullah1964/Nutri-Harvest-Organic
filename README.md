# Nutri Harvest Organics – Power BI Sales Analytics

## Project Overview

An interactive Power BI dashboard developed for Nutri Harvest Organics to analyze sales performance, customer insights, product performance, regional performance, and profitability.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling

## Key Analysis

- Sales & Revenue Analysis
- Customer Analysis
- Product Performance
- Regional Performance
- Orders & Quantity Analysis
- Profit & Margin Analysis
- Return Analysis

## Dashboard

The Power BI report is available in the `.pbix` file included in this repository.
